# 跃传 · HopSend

推荐名称：**跃传**。英文名称：**HopSend**。

一句话介绍：面向可信设备的跨网络文件传输助手。

宣传语：**让文件跨设备抵达。**

“跃”表达跨越设备与网络，“传”直接说明文件传输用途。英文由 Hop 与 Send 组合，便于用作程序名称。
名称表达传输能力，不预设每一次连接都能直连或突破带宽上限。

## 图标设计

深海蓝圆角方形中，两条相反方向的箭头组成双向传输标志。两端圆点代表设备节点。
浅色箭头与青绿箭头区分传输方向，图形保持简单，便于缩小为 Windows 应用图标。

| 颜色 | 色值 | 用途 |
|---|---|---|
| 深海蓝 | #173E58 | 品牌主色、深色图标底色起点 |
| 深夜蓝 | #0C2338 | 图标底色终点 |
| 青绿 | #39DCC7 | 传输方向与交互强调 |
| 冰白 | #F3FAFF | 深色背景上的图形 |
| 深青绿 | #16A99B | 浅色背景上的标志 |

## 文件用途

- `hopsend-icon.svg`：应用图标矢量源文件，可编辑并任意缩放。
- `hopsend-icon-1024.png`：透明圆角外部背景的高分辨率应用图标。
- `hopsend-icon-16.png` 至 `hopsend-icon-512.png`：常用尺寸的 PNG。
- `hopsend.ico`：Windows 多尺寸图标，包含 16、20、24、32、40、48、64、128、256 像素。
- `hopsend-mark.svg` / `hopsend-mark-1024.png`：适合浅色背景的透明底独立标志。
- `hopsend-monochrome.svg`：继承 `currentColor` 的单色图形，供工具栏等场景着色。
- `hopsend-brand-preview.png`：名称、图标与宣传语组合预览。

这些图标从 SVG 源文件直接渲染。图形内未使用文字或外部字体。

## 软件中的建议命名

```text
桌面窗口标题：跃传 HopSend
副标题：跨设备文件传输助手
桌面主程序：hopsend.exe
节点服务：hopsend-agent.exe
诊断工具：hopsend-cli.exe
默认下载目录：HopSend Downloads
```

可在架构工作台的项目名称处使用“跃传 HopSend”，保留原有技术模块名称，以便讨论实现。
