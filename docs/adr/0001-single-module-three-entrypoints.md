# ADR 0001：一个 Go 模块与三个入口

状态：工程初始采用。日期：2026-11-22。

## 背景

桌面端、Agent 与 CLI 共享 Go 传输内核，但前端构建只属于桌面端。
需要保持目录清楚，并在开始阶段避免多模块依赖维护。

## 决定

- 工程根只有一份 go.mod；不使用 go.work。
- apps/desktop、apps/agent、apps/cli 分别作为程序入口。
- Wails 根配置位于 apps/desktop，前端位于其 frontend 子目录。
- 内核和平台适配均在根 internal；入口负责依赖注入。
- CLI 先用于 P0/P1 验证，桌面端之后接入同一组用例。

## 影响

Wails 初始化模板必须适配此目录，不能产生第二份嵌套模块。
Agent 和 CLI 不依赖桌面框架；go test 的范围与平台构建依赖需在桌面引入后按实际情况调整。
未来只有在版本发布节奏和依赖隔离确有需要时再拆模块，并记录新 ADR。
