# ADR 0014：显式发布路径索引与不可变下载版本

- 日期：2026-11-26
- 阶段：P2.16a（协议/源端核心），P2.16b（桌面闭环）
- 状态：已实现；自动化、本机真实协议及待现场范围分别见 [P2.16a](../validation/P2.16a-published-path-index.md)和 [P2.16b](../validation/P2.16b-path-download.md)

## 决定

新增受认证 `GET /v1/shares/{id}/index?path=...`，能力名 `published_path_index`。沿用共享读取授权；只写凭据不获得索引访问权。路径必须是规范的共享内相对路径，不能是绝对路径、反斜线、链接或 Windows 特殊名称。返回该路径最后一次显式发布的 manifest ID、内容 SHA-256、名称、快照字节数、类型和 UTC 发布时间，不包含本机绝对路径。

索引指向**已发布快照**，不是对实时源内容的相等断言。源端改动、同大小替换、删除或重新创建，不会改变旧快照；重新显式发布成功后原子切换索引。目录列表显示实时目录，版本详情必须明确标注“已发布快照”，不能用当前大小/mtime 推断版本。查询不哈希或复制源内容，也不自动触发发布。首次没有索引返回 404 `path_unpublished`；索引、清单或对象不一致返回 409 `index_stale`，不猜版本、不降级到同名文件。旧 Agent 不宣告能力时客户端保留手工 manifest 入口。

## 源端发布与一致性

由源设备所有者通过本地 CLI 的 Agent 配置、共享 ID 和相对路径显式发布；远程读取凭据不能要求服务器进行大文件复制。源通过 `os.Root` 约束打开，拒绝链接/重解析点，目录沿用有界目录包格式。内容复制到独立对象并完整 SHA-256 后同步，发布不可变对象及清单，最后同步并原子替换索引；失败或取消保留原索引。单内容库使用跨进程排他锁，一次只允许一个发布者，竞争者立即报忙；不建立无界发布队列。

内部记录绑定共享 ID、精确相对路径、共享根的文件系统身份和清单摘要。配置指向其他根（包括同路径根目录替换）不能复用旧索引。记录使用共享/路径摘要作为文件名，避免将客户端路径直接拼入内容库。内容库不得位于待发布文件夹内部。索引更新失败可能留下未引用对象，不删除旧版本，不在此阶段实现垃圾回收。

查询校验小型索引、manifest 和对象类型/长度，不重新读取整份对象。管理员或磁盘后来改变对象字节由传输时逐块与完整 SHA-256 拒绝；索引不冒充磁盘完整性巡检。已经取得的 manifest ID 始终固定下载版本；后续再次发布不会切换进行中的任务。普通文件系统不是 VSS 一致性快照；发布检测观察到的源身份、结构、大小和时间变化，不能承诺检测对抗性的并发写入并恢复元数据。需要应用一致性的文件应先由所有者停止写入或生成应用快照。
