# ADR 0006：已配对设备在连接前自动准备

状态：采用。日期：2026-11-23。

问题：P2.4 依赖开发联调启动的临时 Agent。测试结束停止后，用户打开桌面只能看到 HTTPS 超时，必须手工运行远端进程，缺少正常使用前的准备步骤。

决定：设备明确启用托管后，经已验证 SSH 身份检查已有配置；部署配套 Agent 并以 SHA-256 验证，启动后完成独立 HTTPS 授权与真实 SFTP 写入/回读探测，再进入传输。桌面保存配置即验收，下载/上传/诊断自动预检，传输重试前检查并恢复。程序部署通过随机暂存及禁止覆盖发布避免半成品版本。

首次系统安装、Tailnet/密钥/证书信任仍需要所有者授权；本功能不自动放行防火墙或更换信任。保留手动管理模式，不把所有 SSH 登录都视为允许部署程序。

生命周期：前台 SSH 执行通道由桌面持有，不能把 Windows 的瞬间后台 PID 当作服务就绪。每次连接以实际 HTTPS 探测为准，既可复用仍健康的进程，也可恢复已退出的进程。独立开机自启和系统服务由 P4 后续实现。
