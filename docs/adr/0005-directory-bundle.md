# ADR 0005：目录包复用可靠传输内核

日期：2026-11-23；状态：采用。

P2 先把目录整体版本表达为无压缩 TAR 加末尾 JSON 索引。索引记录空目录、相对路径、文件尺寸和 SHA-256；manifest v1 增加可选 payload_kind=folder。原普通文件字段和 ID 计算结果不变，新类型由新客户端识别，旧客户端会拒绝未知字段。
不引入另一套分块确认协议，继续复用既有下载和接收端确认上传。打包和展开有额外磁盘占用，当前用不压缩格式使包体尺寸能够约束实际展开数据量，避免压缩倍率导致容量估计失真。

正式目录出现前完整校验所有内容；同卷禁止覆盖重命名发布整个目录。目录包缓存保留在任务/会话数据区，支持发布后退出、磁盘损坏与状态事务的对账。不能因为目标路径存在就认为任务已完成。
为避免危险的目录合并语义，现有同名目录不自动接纳。包中路径由 Windows 安全规则和 os.Root 双层约束，拒绝链接、重解析点和重复大小写名。

这一阶段不提供单文件级目录调度、增量同步或自动垃圾回收。后续可通过新的目录契约和 task_files 实体扩展，不能悄悄改变已保存包任务的内容版本。
