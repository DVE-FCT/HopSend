# ADR 0002：按已核对的主机密钥选择 SSH 协商算法

日期：2026-11-23。状态：采用。

## 背景

Windows OpenSSH 同时公布多种主机密钥。只配置 HostKeyCallback 时，SSH 默认算法顺序可能选中用户尚未核对的另一种公钥，导致合法连接失败。
不能为了消除错误而关闭主机检查，或把扫描到的全部公钥直接加入信任。

## 决定

固定 github.com/skeema/knownhosts v1.3.1，复用其在 x/crypto/ssh/knownhosts 之上的目标算法查询。算法提案限制为该主机已信任且当前 SSH 库仍列为安全的算法。
协商后仍由完整 HostKeyCallback 验证公钥；支持普通和散列 known_hosts。不存在受支持的已信任主机密钥时提前拒绝。

## 验证

多算法服务只保存 ED25519 的普通/散列信任记录，旧实现均失败，修复后成功。变化/未知公钥继续拒绝，并已在真实两台 Windows 上核对样例文件哈希。

## 影响

增加一个固定版本的小型依赖，保留 go.sum。旧的 SHA-1 算法不因存在于 known_hosts 就重新启用。
后续新增交互配对时，先核对身份再更新信任记录，不能把算法协商自动变成信任扩张。
