# ADR 0007：Windows 支持范围与逐步分发

状态：采用（范围与规划决定，后续分发功能尚未实现）。日期：2026-11-23。

当前承诺：Windows x64 桌面、Windows OpenSSH/SFTP 和 Windows Agent 的实测组合。Go 内核保留与 Wails 分离的接口，包内测试在其他系统可构建不代表 macOS/Linux 已受支持。新增平台需验证路径大小写、权限、链接、Sync/重命名、SSH/证书存储、恢复、打包和真实收发后再独立声明支持。

P2.5 已提供无需开发工具链运行的 EXE 与按需 SSH 管理 Agent；它不保证桌面退出或账户注销后的无人值守。P2.8 提前交付有校验清单的 ZIP、首次安装/配对指导、用户登录计划任务及升级卸载，验收桌面关闭和重启登录后的 Agent 健康。账户登录触发与机器启动触发明确区分。P4.2 才交付机器级服务及无需用户登录的完整安装体验。

不选择立即同时支持多个桌面系统：会扩大路径/权限和部署的未知边界，当前优先把 Windows 的真实使用闭环完成。也不把临时 SSH 子进程称为后台服务，或默认让标准账号创建管理员任务。

共享凭据、SSH 主机信任、HTTPS 信任、文件 ACL 继续分别管理。升级/卸载要区分程序缓存、活动任务、暂存数据、用户正式文件和凭据；不得为了清缓存破坏正在恢复的任务。具体完成条件见 [阶段规划](../04-roadmap.md)。
