# 网络诊断、监控与界面

## 桌面操作

“网络诊断”选择已配对设备后开始检查。逐层展示 Tailscale 设备/路径、HTTPS 与 SSH 端口、HTTPS 证书与 API 授权、SSH 主机密钥/公钥认证。填写可信清单 ID 后，实际读取第 0 块并核对 SHA-256；这会产生真实网络流量，较大的中继块可能耗时数分钟，可停止诊断。

设备可见、TCP 通、身份可信与字节正确是不同结果。未指定清单、空文件或前置授权不通过时，不把字节验证写成通过。结果带观测时间；路径来自目标 SSH 设备的本机 Tailscale 活动连接快照，仅 Online、Active 且 CurAddr 非空时报告直连，Active 且只有 Relay 时报告中继；无证据则显示待确认。路径会随网络变化，不是持续测速或未来保证。

任务页可筛选全部、传输中、已完成和待处理。右上角可切换浅色/深色主题并本地保存。深蓝导航、青绿色操作、绿色完成、琥珀色等待和红色错误同时配文字；键盘焦点有可见边框。

## 速度与进度口径

- 已校验进度：现有引擎的唯一确认分块字节，下载在校验/Sync/SQLite 确认后计入，上传以接收端确认计入。重传不累计多份有效进度。
- 本次传输：当前 Start/Resume 执行以来的 SFTP 应用数据，下载统计实际交付给写入器的字节，上传统计 SFTP 写入已返回的字节。包括重传，排除 SSH/TLS/WireGuard 等协议开销；上传传递字节仍不等于接收端哈希确认。
- 传输速度：最近约 5 秒的上述应用数据滑动平均，按 250 ms 桶合并采样，长时间无数据自动归零。正在连接、重核验、等待、暂停、完成和异常时为零。
- 预计剩余：本次传输尝试开始后新增的有效确认量和耗时估算，重试后重新设定已有块基线；至少一个新块确认且最近仍有数据时才显示。暂停/重试/慢盘/网络波动会改变估计，校验和发布耗时未计入。
- 速度与本次传输量是当前进程执行指标；历史任务重开后不伪造旧测速数据。最终正确性和恢复状态仍由 SQLite/原清单决定。

## 活动记录

Manager 在数据库同级 logs/tasks.jsonl 记录实际任务状态变化，超过约 1 MiB 后轮转到 .1。活动页读取当前文件最近 200 条；关闭重开仍可读取。日志不记录设备配置或凭据文件正文，系统错误可能带本机运行路径，请按本机资料处理。日志写入错误会在读取活动页时报错，不替代可靠传输状态，也不是安全审计账本。

## CLI

```powershell
./dist/cli/hopsend-cli.exe diagnose `
  --url https://源设备地址:9443 --ca-cert D:/HopSendTrust/ca.crt `
  --token-file D:/HopSendTrust/client.token `
  --address 源设备地址:22 --user 专用账号 `
  --key D:/HopSendTrust/id_ed25519 --known-hosts D:/HopSendTrust/known_hosts `
  --share files --manifest 已发布的64位清单ID
```

未填 manifest 只检查网络和身份；failed 层使 CLI 返回 1，unknown/skipped 保持明确标记。整个诊断默认最多 11 分钟，实际数据探测最多 10 分钟。诊断不会修改 Tailscale、服务或防火墙。
