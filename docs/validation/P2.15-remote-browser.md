- 范围：只读目录的应用层、Wails 桥接、前端组件、按页导航及错误恢复。P2.16 点选版本下载和 P2.17 上传父目录不混入。

## 实际交付

“从设备下载”页新增可折叠目录浏览器，展开才读取已选设备的授权共享。支持共享切换、100 项分页、返回上级/根、中文和空目录、文件详情、观察时间和完整/未完遍历标志。目录变化或续页错误后清空旧列表，显式从第一页重读；最多聚合 100000 项，不将此上限写为已测性能。

Go 应用层只接收 HTTPS Agent 配置，不接收 SSH 或管理部署参数。每次查询验证分页能力、共享权限和页结构，并保留结构化错误给 UI。只写共享禁止枚举；旧 Agent 缺少分页能力时要求升级。浏览不会部署、发布或开始传输；托管设备提供显式准备按钮，非托管提供诊断和升级说明。每次查询总超时 15 秒，前端用请求代次丢弃晚到结果，下一页防重入。

## 实际验证

环境：Windows amd64、Go 1.27.4、Node 24.14.1、pnpm 11.25.0、Wails 2.17.1。

| 检查 | 真实结果 |
|---|---|
| App 桥接 → 本机 TLS | 使用真实 App 和受证书保护 HTTP 服务；仅 GET capabilities/shares/entries；ManageAgent=true 且 SSH 无效仍能浏览；未改设备配置或生成 devices.json |
| Go 用例 → 实际 Agent | 1005 个文件加一个中文子目录，100 项/页，共 11 页；逐项去重/数量/头尾检查通过；中文空目录返回空数组 |
| 游标变化 | Agent 实际增添文件后返回 cursor_stale，Go 保留错误码且不返回部分页 |
| 权限 | 读取授权外共享拒绝；实际 upload_only 凭据可见 write_only 共享，目录读取被拒绝 |
| 输入/能力与错误 | 越界/绝对/反斜线路径拒绝，取消请求失败；旧 Agent 提示 browse_unsupported；重复共享响应拒绝；远端错误结构保留 |
| 前端生产状态测试 | 七项通过：1005 项完整遍历/空目录、变化重读、晚到设备/目录/关闭结果、只写拒绝、共享与凭据变更隔离、重复/错范围/停滞游标、下一页防重与非法路径；UTF-8 顺序包含补充平面字符 |

## 限制

现有真实 Agent 的授权、目录越界/链接和分页变化测试随全量回归运行；新用例没有更换证书或跳过验证。未修改 Agent/控制协议，不增加路径到内容版本的猜测字段。

没有把 UI 桩当作原生 Wails 点按、第二台物理目录枚举、SFTP 传输或干净系统安装；原生自动化窗口不可操作的限制沿用 P2.14 记录。列表不是事务快照，也不能证明内容版本，文件详情明确提示仍需清单 ID；未提供远端新建/删除/改名。P2.8 源端首次授权仍单独待验收。
