# P0.3 HTTPS Agent 控制接口验收

日期：2026-11-22。分支：test/p0.3-agent-control。

## 交付

- Agent 前台入口，TLS 1.3、设备凭据与按 share_id 的只读授权。
- 四个 GET：health、capabilities、shares、shares/{share_id}/entries；OpenAPI 3.1 契约与共享 Go DTO。
- CLI agent-init 生成独立证书/随机凭据/配置，agent-status 执行受认证查询。
- 默认回环监听；拒绝未知配置字段、无效授权、路径越界和目录链接。未提供上传、manifest 或 SFTP 服务端。

## 实际验证

1. check-go.ps1 -StrictDoctor：格式、vet、全部测试、CLI/Agent 编译与版本检查通过。
2. 真实回环 TLS 服务验证受信任证书、两套设备凭据的共享隔离、中文文件目录与 CLI 查询。
3. 未知 CA、错误主机名、错误/缺失 Token、未授权共享、路径越界、Windows ADS 路径被拒绝。POST 及未知接口返回结构化错误。
4. 本机没有符号链接创建权限，改用实际 NTFS junction 验证目录链接拒绝，通过；没有把无法创建的 symlink 场景假写成已执行。
5. 编译的 Agent 与 CLI 作为独立进程启动，通过 HTTPS 查询到真实样例目录；初始化已有目录被拒绝，无覆盖。
6. OpenSSL 3.5.5 客户端严格验证生成证书链通过；四个成功响应及 401/400/404 错误响应按公开 OpenAPI 中的 JSON Schema 校验通过。
7. 测试曾发现叶证书缺 AuthorityKeyId；已通过解析生成后的 CA 再签发叶证书修正，并增加证书身份检查。修正后重新执行完整检查、进程验收及外部 TLS/schema 验证。
8. P0.2 PR #3 的 Windows CI 均通过；合并后回读主分支并执行回归。P0.3 从该 main 创建。

## 限制与待现场验收

- 本机 TCP/TLS 和两个进程验证不等于两台物理设备。Windows OpenSSH Server、Tailscale 直连/中继和局域网速度仍待现场验收。
- Go race 检测未执行；Windows 安装器、后台服务、系统 ACL 配置、WebView2 与桌面 UI 未实现。
- Token 文件及私钥的实际 Windows ACL 需要在部署时确认；当前没有系统级凭据保管、吊销界面或自动续证。删除凭据配置并重启 Agent 可撤销该身份。
- 服务器证书有效期 30 天，CA 签名私钥不落盘；到期重新生成并重新配对。
- 目录接口单次上限 1000 项，无分页。公开契约只描述当前四个已实现接口，capabilities 不宣称有未来上传能力。

结论：P0.3 控制接口实现和本机验收完成，代码可进入测试分支与 PR；跨设备网络能力仍有独立现场验收项。
