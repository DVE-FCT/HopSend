## 交付

桌面完成受信回应导入和设备保存后，立即按 manage_agent 选择 PrepareDevice 或只验证身份的 CheckDevice。验收失败返回含原 Device 的结果，不抛作配对资料失败，不重复导入，不删除设备。返回设备列表后提供诊断入口；诊断组件接收预选 ID 和选择序号，重复从同一设备跳转也可重新定位。

PairLocalIdentity 仍自动读取 Running 状态中的规范 IPv4，跳过 IPv6。读取失败显示手动输入；PairCreateRequest 再验证实际已启用的本机 Tailscale 网卡地址。可读状态不能被手动网卡回退覆盖。缺少有效网卡或地址不匹配时不创建密钥。

只读健康检查首次加载、切到设备页、手动刷新和每 30 秒定时运行，共用最多两个探测的队列，重入合并。失败也记录探测时间，定时失败不会每 750ms 重试或刷全局日志。组件卸载停止后续队列与状态发布，后端已发请求最多等待既有六秒超时。

## 验证

环境：Windows amd64，Go 1.27.4、Node 24.14.1、pnpm 11.25.0、Wails 2.17.1。

- 前端生产流程测试：托管/非托管分支；网络失败保存身份；最多两个观察、批次不重入、失败节流和停止后不发布结果。
- Go App 测试：手动地址必须来自本机网卡，拒绝其他 peer、回环、非规范字符串、IPv6；状态可用时不接受备用地址。
- 本机 TLS 集成：托管设备即使 SSH 配置无效，ObserveDevice 仅执行认证 GET /v1/health；错误 Token 不能显示可达。
