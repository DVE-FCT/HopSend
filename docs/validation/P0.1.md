## 实际验证

1. `scripts/check/check-go.ps1 -StrictDoctor`：格式、go vet、go test、CLI 编译、version 冒烟与四工具固定版本检查通过。
2. 单元测试覆盖 doctor 缺失/版本不符/正常，以及 CLI JSON、未知命令与无效参数。
3. 使用暂存源码树导出到独立目录，设置独立空 GOCACHE，执行 vet、test、build，CLI 能启动。未借用现有源码编译产物。
4. 从构建的 CLI 进程移除 PATH 中开发工具路径：doctor --strict 报告四工具 unavailable、ready=false，退出码为 1。
5. Git 差异格式检查通过。S0 先经 PR #1 合并并回读验证；P0.1 分支从该 main 创建。

## 边界

干净验证指源码导出与空编译缓存，不是全新 Windows 系统。Wails CLI 可运行不代表 WebView2、桌面构建或界面验收通过。
没有实现文件传输或 Agent。本阶段不需要真实远端设备。CI 是否成功以 GitHub 实际作业状态为准，不把新增工作流等同于已执行成功。
