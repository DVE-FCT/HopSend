# P1.1 内容清单与可信分块下载验收

日期：2026-11-23。分支：test/p1.1-verified-download。

## 交付

- manifest v1 Go 类型、JSON Schema 及控制接口 OpenAPI 更新。
- CLI publish 生成独立、内容寻址的只读快照；不使用可变源文件硬链接。
- Agent 按身份和共享授权提供版本清单，客户端验证请求 ID、共享、结构、边界与内容标识。
- 可复用 Go 下载用例与引擎、CLI download、每 worker 独立 SSH/SFTP 连接。
- 有界流式按偏移写盘；每块通过长度/哈希校验并同步，最终重新读取整文件验证后才原子发布。
- 目标同名或验证失败不覆盖用户文件，取消不发布未完成文件。

## 自动验证

- 空文件、精确整块、不足一块的末块、中文文件名。
- 清单标识或字段被改、路径越界和 Windows 保留名、非法偏移/长度、超过 4 GiB 的 64 位分块边界。
- 发布后修改原文件，快照保持原内容；相同发布可复用，损坏对象拒绝复用。
- 错误分块哈希、错误全文件哈希、取消和最终目标竞争均不发布或覆盖目标。
- 真实 HTTPS 清单查询 + 两个真实 SSH/SFTP worker + 实际文件下载，输出字节与原始样例完全一致；CLI 同一路径通过。
- 格式、go vet、全套 Go 测试、CLI/Agent 构建和固定工具链诊断。

## 两设备现场验证

源节点为 Windows 10 OpenSSH，客户端为 Windows 11；沿用先人工核对主机指纹再认证的规则。
远端标准用户运行 Agent，独立 Tailscale 地址的 TCP 9443 已由管理员按客户端地址单独放行，不使用 SSH 端口转发。
客户端直接通过 TLS 1.3 和已配对 CA 验证 health、清单、API 凭据和共享权限；清单实际响应按 JSON Schema 校验。

源端真实写盘 5 GiB＋17 字节（5,368,709,137 字节），先独立计算完整 SHA-256，再生成副本与 161 块清单，快照与原文件哈希一致。
客户端实际下载全部 5,368,709,137 字节，161 个块全部通过；最终发布后独立重读目标文件计算 SHA-256，与源端独立哈希、快照哈希和清单 content_id 四者一致。暂存文件已按设计移除。

实测耗时约 583.7 秒（包括最终独立重读验证），仅代表本次环境；临时 Agent 已停止。阶段本机与现场正确性验收通过，CI 状态以 PR 作业为准。

## 本阶段边界

- P1.1 仅开始新下载，保留失败暂存但不声称已支持续传；SQLite 与任务恢复在 P1.2。
- 当前现场网络仍是同一局域网的 Tailscale；不同宽带/移动数据将在后续恢复场景执行。
- 1 MiB 缓冲和并发是实现参数，现场用大文件证明正确性，不把单次结果写成普遍带宽保证。
- 机器地址、账号、私钥、Token、配置和大测试文件不进仓库；公开记录使用脱敏环境描述。
