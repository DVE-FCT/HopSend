## 独立交付

`contracts/pairing/v1` 定义资料 DTO；`internal/pairing/material` 负责 Ed25519/OpenSSH 密钥生成、请求、严格 ZIP/JSON 校验、指纹核对、本机私钥绑定及原子信任导入；CLI 提供 `pair request|inspect|import`。业务失败提供 `stage/code/message`，输出不包含 Token 或私钥原文。

正常业务不启动 PowerShell、ssh-keygen 或网络连接；Windows 直接使用原生 ACL。生成或导入时先准备账号专属目录，再写入资料；新信任在同目录暂存、文件 Sync 后一次重命名发布，既有信任不覆盖。`inspect/import` 的 `verification=not_run` 明确区分本地资料验证与真实连接验收。

## 实际验证

环境：Windows amd64，Go 1.27.4、Node 24.14.1、pnpm 11.25.0、Wails 2.17.1。所有测试密钥、证书、Token 和回应均为临时生成的合成资料，不进入仓库。

| 检查 | 结果 |
|---|---|
| Go 生成 Ed25519/OpenSSH 私钥 | 解析出的公钥与请求一致；私钥不进入公开请求 |
| 有效旧格式回应与导入 | 生成五个完整配对文件；连接配置只含文件引用 |
| 重复导入 | 相同回应重试返回同一配置，接受连接 JSON 格式差异但不重写既有信任 |
| 更换 Token、私钥不匹配 | 分别返回 `trust_conflict` / `private_key_mismatch`，原信任未覆盖，错误密钥不发布配置 |
| 导入锁竞争、已取消上下文 | 被拒绝且不发布新信任；释放锁后可重试 |
| 18 组坏回应 | 错误 SSH/CA 指纹、请求/IP 绑定、额外/重复/越界/链接 ZIP 项、单项/总包过大、CRC 损坏、无效 CA/Token、重复/未知/额外 JSON、路径越界及地址不一致均拒绝，未生成 `paired/` |
| 请求 JSON | 重复键、字段大小写混用、额外对象和无效 UTF-8 拒绝 |
| 非法源 IP | 非 Tailnet、非规范写法或带掩码等均拒绝，不创建信任目录 |
| 原生 NTFS ACL | 私钥、请求、Token、连接配置和回应缓存仅授予当前账号/SYSTEM；重复保护缓存成功 |
| Windows junction | 信任路径经过目录链接时拒绝，原信任保持可读 |
| 编译 CLI 与系统互通 | Go CLI 生成请求 → Windows OpenSSH `ssh-keygen -y` 读取 Go 私钥 → WinPS5.1 用旧字段和 Compress-Archive 生成 ZIP → Go CLI inspect/import → 同一回应重试，完整通过 |
| CLI 错误与输出 | 坏 CA 指纹返回结构化错误；inspect/import/config 输出未包含测试 Token 或私钥 |
| 严格检查与构建 | TS/Vite、gofmt、go vet、无缓存全量 Go 测试、CLI/Agent 构建及固定工具链诊断通过；Wails Windows 生产构建通过 |

执行：

```powershell
go test -v -count=1 ./internal/pairing/material
go test -v -count=1 -timeout=150s ./tests/e2e -run TestPairMaterialsGoCLIAndLegacyPowerShell
./scripts/check/check-go.ps1 -StrictDoctor
./scripts/build/build-desktop.ps1
git diff --check
```

编译 CLI 互通测试实际执行 Windows OpenSSH 和 Windows PowerShell 5.1，不只是两个 Go 函数互调。含空格、中文、单引号和命令样式显示名称的路径/参数均作为字面数据处理，未触发系统服务、提权或真实网络传输。

## 边界

- 本阶段不迁移接收端全部资料生成和 Windows 授权编排，不安装或修改防火墙、Tailscale、sshd、计划任务。
- 本次未重新执行两台物理设备的在线配对和上传；此前 preview.13 的现场结果不能冒充此次迁移后的现场结果。第三台干净系统仍未验收。
- 信任目录须为本账号控制的本地目录；未测试恶意同账号进程、所有网络文件系统、磁盘写满或物理断电。文件 Sync 与重命名不是这些故障已通过的证明。
- CLI 只固定资料；真实连接仍执行原有证书、主机密钥、权限及 SFTP 检查。错误资料被拒绝后不会自动替换原信任。
