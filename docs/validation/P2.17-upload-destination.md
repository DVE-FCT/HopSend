# P2.17：上传目的子目录验收

- 日期：2026-11-27
- 分支：test/p2.17-upload-destination
- 基线：P2.16 合并 8865456

## 交付

控制契约修订 0.5.0，新增可选 `parent_path` 和 `upload_parent_path` 能力。根为兼容默认值；非根为共享内已有规范目录。上传会话在 SQLite v3 保存父目录及共享根/父目录身份，幂等重取、查状态、确认块、finalize 全部核验。暂存留在共享根受控区，SFTP 不经过可变化的父路径；Windows 控制操作持有禁止重命名的目录链句柄。正式发布同卷、拒绝覆盖。

CLI 增加 `--parent-path`；桌面 `StartUploadTo`、恢复源记录和任务目标绑定父目录。上传页复用 P2.15 浏览器，读写共享可以选目录，只写共享仅手工相对路径且不发目录请求；换设备/共享清空旧选择，不选择其他共享作为隐式回退。

v1/v2 数据库先一致备份再迁移，使用 `BEGIN IMMEDIATE` 串行迁移并重查版本；备份保留原 schema 和已提交 WAL 数据。旧会话没有绑定，不自动赋予身份，返回 `upload_parent_unbound`。旧软件不支持 schema v3，回退边界见使用说明。

## 实际结果

1. 真实本机 TLS Agent + SSH/SFTP 上传嵌套中文父目录，字节和最终位置正确；根目录没有误收同名文件。只写凭据仍不能列目录。
2. 中文文件夹、中文文本、空目录和空文件发布到选择的位置；完成会话重取/对账通过。
3. 上传中按已确认块暂停、关闭管理器并重新建立管理器，从 SQLite 恢复；仍发布到原父目录，最终字节一致。
4. 父目录被移走并以同名新目录替换后，状态、finalize 和幂等重取均返回 `upload_parent_changed`，没有发布到替代目录；原目录恢复原路径后可继续核验。关闭并重建 Agent 对象后，原目录的会话可查询，替换目录仍被拒绝。
5. 越界、Windows 特殊路径、缺失目录和本机 NTFS junction 拒绝。隔离测试目录的 NTFS 拒绝读取条件被正确拒绝，未分配暂存；测试后恢复其 ACL。
6. Windows 目录链租约测试：初版仅属性权限没有阻止重命名，修正为参与共享访问检查的读取句柄后，持有期间重命名被拒绝、释放后成功；超过传统 260 字符的中文父路径同样通过。
7. SQLite v1 下载记录和 v2 上传记录迁移保留数据，不补造父目录身份；一致备份保留旧版本和已提交 WAL。六个并发打开者可完成同一次迁移，未来版本数据库仍拒绝。
8. 旧能力 Agent 在复制源快照或 POST 前拒绝子目录上传。新根目录请求省略 `parent_path`，旧根入口保留；缺少绑定的旧会话被明确拒绝。
9. Playwright 实际 Vue 界面使用明确标注的演示桥接：目录选择写回、任务参数绑定、切共享清空、只写无目录表/无读取请求、手工路径和 1080px 深色无横向溢出通过。截图：仓库外 `outputs/maintenance-20261126/output/playwright/p217-upload-parent-dark.jpg`，不作物理设备传输证据。
10. TypeScript/Vite、20 项前端状态、gofmt/vet、未缓存全量 Go 测试、四项固定工具诊断、基线文档/钩子检查及实际 Wails Windows EXE 构建通过。新增数据库并发/备份实现随后由 SQLite 包重新验证，最终快照仍须经 PR CI。

## 边界

尚未执行本阶段新增界面的原生文件选择/两台物理 Windows 完整操作，不将浏览器夹具冒充现场。第三台干净系统和 P2.8 的完整组合仍待现场，P3.x 合并门槛保留。空间不足沿用拒绝超容量而不分配大文件的测试；专用小卷实际写满、物理断电和服务守护仍属 P4，不填系统盘。

没有实现远程新建目录、批次上传或自动清理旧会话/备份；不会提升只写权限、改防火墙或自动信任新身份。Windows 是生产范围，其他开发平台的目录句柄不承诺 Windows 的禁止重命名语义。
