# P0.2 SSH/SFTP 协议与本机验收

日期：2026-11-22。分支：test/p0.2-sftp-connectivity。

## 交付

固定 github.com/pkg/sftp v1.13.12、golang.org/x/crypto v0.59.0，提交 go.sum。
实现未加密私钥认证、known_hosts 主机密钥校验、带超时/取消的真实 SFTP 精确范围读取，以及 CLI sftp-read 的哈希诊断。

## 实际验证范围

自动测试启动本机 127.0.0.1 随机端口 SSH 服务，真实执行主机密钥交换、公钥认证、SFTP 子系统、临时文件范围读取；不是替换客户端的模拟响应。

- 指定偏移/长度的字节与源完全一致，CLI 提供可信哈希时核对通过。
- 未知主机、变化主机、错误用户私钥被拒绝。
- 远程文件截断、负偏移、零长度与 64 位范围溢出返回失败。
- 读取开始后取消，阻塞请求在限定时间退出并返回 context.Canceled。
- TCP 可连接但不发送 SSH 握手时，截止时间终止请求。
- Go 格式、vet、全套测试、CLI 构建和固定工具 doctor 检查通过。

P0.1 PR #2 的两个 Windows CI 作业均成功，合并后已回读 main 并执行 Go 回归。P0.2 从该主分支开始，无需解决集成冲突。

## 完成边界

本阶段的协议实现和本机真实网络验证完成。尚未取得第二台可操作设备，未执行 Windows OpenSSH Server 现场联调、跨局域网/Tailscale 或吞吐测量；相关表格和步骤见 docs/09-p0-device-runbook.md。
此限制不伪装为通过，也不声称完整下载、断点恢复或 Windows 系统服务已实现。代码同步的范围仅为已验证的协议能力。
