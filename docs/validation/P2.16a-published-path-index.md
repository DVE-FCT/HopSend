# P2.16a：显式发布与路径版本索引验收

日期：2026-11-26

## 范围

本子阶段交付 Agent 的 `GET /v1/shares/{share_id}/index?path=...`、`published_path_index` 能力、源端所有者主动执行的 `publish-path` CLI，以及 Go `publication.Publish` / `nodeclient.PathIndex`。索引只返回最后一次显式发布的不可变版本；它不读取实时源内容来猜 manifest，也不启动 SFTP 或桌面传输。桌面点选下载属于 P2.16b，未在本记录中声称完成。

## 实现

- `contracts/control/v1` 新增 `PathVersion`，绑定共享 ID、规范相对路径、manifest/content SHA-256、快照大小、类型和 UTC 发布时间。
- Agent 仅对已认证且具有读取授权的共享提供索引；只写身份不能浏览或查询索引。
- 源端 `hopsend-cli publish-path --agent-config ... --share files --path ...` 检查共享内路径、链接/重解析点、源与内容库边界，复制并完整校验不可变对象后原子更新索引。
- 索引使用共享根文件系统身份；共享根被替换、索引/manifest/object 不一致时返回 `409 index_stale`。未发布返回 `404 path_unpublished`，不降级到同名文件或大小/mtime 推断。
- OpenAPI 更新为 0.4.0，并记录 ADR 0014 的版本和一致性边界。

## 验证结果

已执行：

1. `go test ./tests/integration -run 'TestPublishedPathIndex' -count=1 -v`：通过。
2. 真实 TLS Agent 集成：未发布先返回 `path_unpublished`；发布后返回 manifest/content ID；源文件改为同长度新内容时索引仍固定旧版本；重新显式发布后原子切换到新版本。
3. UTF-8 中文路径、路径越界和只写凭据权限：通过。
4. `go test` 覆盖 `internal/publication`、manifest、folder、Agent HTTP API、nodeclient、CLI：通过。
5. 文件夹/空文件发布、取消保留旧索引、排他发布锁、共享根身份变化、损坏索引及源路径/索引目录链接拒绝：通过。本机 NTFS junction 测试实际执行。
6. `scripts/check/check-go.ps1`：TypeScript/Vite、14 项前端状态检查、gofmt、go vet、未缓存全量 Go 测试和 CLI/Agent 构建通过。基线检查的文档链接、中文钩子与分支限制通过。

## 边界

- 本阶段没有把 P2.16b 的桌面“点击文件→选择目的地→创建下载任务”标作完成。
- 索引是显式发布快照引用，不是实时文件系统事务快照；源文件应用一致性仍由所有者保证。
- 内容对象垃圾回收、源端图形发布页、P2.17 上传子目录和 P2.8 干净 Windows 现场验收仍是后续工作。
