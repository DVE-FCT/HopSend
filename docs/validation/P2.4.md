# P2.4 诊断、监控与界面验收

日期：2026-11-23；分支：test/p2.4-diagnostics-metrics。

## 交付

CLI diagnose 与桌面独立网络诊断页，逐层区分 Tailscale、TCP 端口、HTTPS/API、SSH 信任认证与选填清单的真实 SFTP/哈希探测。保留观测时间和路径证据，没有活动路径不推断直连或中继。桌面调用 Tailscale 时隐藏临时命令窗口，不修改系统网络设置。

SFTP 实际交付/返回的应用字节计数、约 5 秒滑动速度和基于新确认字节的 ETA；重核验不算网络量，重传不虚增有效进度。日志只记录实际状态变化，轮转并支持重开读取；不把日志当恢复正确性来源。

界面统一深蓝导航/青绿操作、明暗主题、本地主题保存、状态文字及颜色、任务筛选和 SVG 图标。多根诊断组件直接使用 v-show 曾造成跨页显示，修复为真实包装容器后逐页验证；没有把该初版问题当作验收通过。

## 自动检查与真实协议验证

- 完整 gofmt、go vet、Go 包/集成/端到端测试及 CLI/Agent 构建，前端 TypeScript/Vite 与实际 Wails production 构建。
- 用实际关闭的回环 TCP 端口、注入的在线 Tailscale 状态验证“设备可见而 SSH 不通”定位；注入状态不是两台真实机器的掉线声明。
- 真实 HTTPS/SFTP 探测读取并验证清单；HTTPS TCP 可达但 CA 无效时，API 层失败，SSH 层可独立通过，字节探测明确未执行。
- 实际上传产生非零速度/ETA，完成后速度归零；已完成任务重新对账不把原有字节算成新传输。
- 实际中断 SFTP TCP 连接并重试，最终有效字节恰为原文件，传输量可包含重传；已有块被复用。
- 用受控时钟验证速率闲置归零、重试后的 ETA 基线和暂停/等待/完成状态；日志重开后仍可读取。
- 实际桌面 JSONL 事件逐条通过 contracts/events/v1/events.schema.json 校验，包含本阶段新增指标。

## 两设备与实际桌面

CLI 和桌面分别验证独立 HTTPS、主机信任、公钥认证，并实际读取 271,360 字节目录包第 0 块，SHA-256 与可信清单一致。此轮路径快照为直连；P1.3 手机热点的 DERP 结果保留为独立证据，不把当前直连记录冒充持续热点验证。

桌面窗口点击创建 64 MiB/64 块下载，完成后确认量与本次传输均为 67,108,864 字节，完成状态速度为零。本机独立重读哈希与源端 Get-FileHash 一致：d6cb5d24d78767f329675486026260e599562d3b46f2a4cdeaeb0d0ff6eafac2。运行时非零速度/ETA 由真实协议集成测试验证；不把静止完成截图当运行测速截图。

测试样本首轮发布到错误内容目录，桌面如实返回 404 且传输量为零；按 Agent 配置解析后的目录重新发布同一清单，随后成功。没有跳过版本授权或改为无认证读取。

实际检查任务、设备、活动与诊断四页：诊断区只在诊断页显示；实际切换明暗主题，浅色和深色均可阅读。实际关闭并重开窗口，深色主题、已完成任务与相同任务状态记录均保留；历史任务不显示上次运行的实时速度。

## 范围

使用临时前台 Agent，不安装服务或修改防火墙。速度为应用数据，排除协议开销；ETA 不含末尾校验/发布耗时，历史任务不伪造旧测速。仍无多节点调度、正式安装包/服务管理、物理断电/写满或竞争检测器验收。目录包缓存保留的边界见 P2.3。
