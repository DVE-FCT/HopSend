# P1.3 任务控制与网络恢复验收

日期：2026-11-23；分支：test/p1.3-recovery-controls。

## 交付与自动验证

- 应用层任务 Manager 提供启动、暂停、继续、取消、状态和退出等待；Wails 后续复用相同实现。
- worker 全部退出且目标锁释放后才结束暂停/取消；发布成功优先记录完成。
- 临时网络错误有界重试，指数退避上限 30 秒；支持等待期间中断。
- API 状态、TLS/SSH 信任、鉴权、版本和哈希错误分类；不会把不可恢复错误统一当网络错误。
- CLI download 默认 6 次重试，control 为已有任务提供本进程交互式控制；不通过修改数据库控制活动 writer。

真实 SSH/SFTP 的暂停/继续完成字节一致，暂停返回后暂存字节和块数保持不变；取消不发布正式文件。
实际关闭已建立的 SFTP TCP 连接，任务进入 waiting_network，重新建连并复用确认块，最终与源文件逐字节一致。
初次连接中断测试发现 pkg/sftp 除 StatusError 外还返回独立的 connection lost 值，已补充分型与回归断言，修复后通过。
另验证有界重试、退避取消、重复执行拒绝、晚到取消不覆盖完成，以及既有持久化/进程退出回归。

热点中继实测发现原整块总时长超时会中断持续推进的慢链路；已将读取超时修正为持续无数据进展的时长。自动测试验证持续写入可跨越初始时限，停止写入后仍会超时；修改后的全套 Go 检查已复跑通过。

已执行全套格式、go vet、Go 测试、CLI/Agent 构建和固定工具链检查；文档更新后执行基线检查。

## 两设备及不同网络

真实独立 HTTPS 不可用时，已存任务进入 waiting_network，随后可立即暂停，不必等待退避计时结束；确认块保留。
用户已切换第二台到关闭 Wi-Fi、使用移动数据的手机热点；观察到 Tailscale DERP 中继，非直连。
跨网络续传已通过：远端临时 Agent 停止时，实际任务进入 waiting_network；启动 Agent 后任务自动重试，通过直接 HTTPS 验证并取得原清单，不建立 SSH 转发。
重核验后复用 159 个块，经实际 SFTP 读取剩余 33,554,449 字节，161 块全部确认。全文件验证、正式发布和 SQLite completed 通过；验收脚本最后独立重读 5,368,709,137 字节，与源端原始哈希一致。

为减少移动数据消耗，预先从已验证的本地完整文件写入并核验 159 个块。此部分明确属于本地缓存，不计作跨网络传输。
仅将最后约 32 MiB＋17 字节计为本次已验证跨网络数据，不把本地缓存写成全量跨网下载。32 MiB 块在该中继路径约耗时 5 分钟，持续进展未触发无数据超时；该速度只代表本次环境。

## 边界

没有部署永久服务、修改额外防火墙或跳过证书/主机信任验证。远端临时 Agent 在现场脚本结束后停止。
本阶段尚无桌面 UI、上传和文件夹闭环；仍按 P2 阶段实现。没有运行物理断电或 race detector 检查。
