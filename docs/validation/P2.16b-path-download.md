# P2.16b：桌面点选版本下载验收

- 日期：2026-11-26
- 分支：test/p2.16b-path-download
- 前提：P2.16a 已通过 PR #24 合并并回读复验。

## 交付

源端“设备与信任 → 发布本机内容”读取所有者选择的本机 Agent 配置，仅展示共享根；支持共享内文件/文件夹选择、显式发布、后台状态和取消，不安装系统组件。配置解析后的摘要绑定当前根和内容库，变化后重新检视；一次只运行一个发布任务，退出先取消并等待释放。原 CLI 保留。

客户端目录浏览器调用 HTTPS 路径索引并再次验证已认证 manifest，显示快照类型、大小、时间和 ID。用户明确点击“下载到…”并选择目的位置后，创建真实任务；不必再手填 manifest。文件夹名称用于进入目录，右侧“查看”用于下载文件夹版本。未发布显示源端操作指引，手工 ID 保留。

本地版本选择限十分钟和 64 项，仅绑定当次设备/信任快照、共享和 manifest。关闭/导航时释放选择，晚到结果丢弃。创建时拒绝变更的设备、过期/已消费选择和重复点击；使用选中共享，不误用设备默认共享。已创建任务保存原清单和连接引用，重新发布不切换任务内容。

## 已执行检查

1. 真实本机 TLS Agent + SSH/SFTP：选中版本后同名同长度重写并重新发布，仍下载原版字节；最终哈希一致。
2. 同一链路下载中文文件夹、中文文本、空文件和空目录，目录结构与内容一致。
3. 传输开始后暂停并释放旧管理器，重新发布源文件，重建管理器后从 SQLite 恢复；任务 ID、manifest 和最终字节保持原版。
4. 生产 App 桥接测试：检视只读；设备变更/过期选择拒绝；按选择共享和版本持久建任务；已消费选择不能重复使用。
5. 源端发布管理器：配置摘要错误拒绝；后台成功、关闭等待、取消状态、未知任务拒绝通过。
6. 前端五项状态测试：未发布/不一致响应拒绝、晚到选择释放、取消保存及导航不建任务、重复点击只创建一次、失败保留选择用于显式重试。
7. Playwright 真实浏览器加载实际 Vue 页面及明确标注的演示桥接数据：未发布、版本详情、保存取消、创建一次、文件夹导航失效、源端配置选择/显式发布及 1080px 深色布局无横向溢出通过。截图保存在仓库外 `outputs/maintenance-20261126/output/playwright/p216-*.jpg`。这些截图不作为两台物理设备的传输证据。
8. 全量 gofmt/vet/未缓存 Go 测试、19 项前端状态测试、TypeScript/Vite、基线文档/钩子检查及实际 Wails 2.17.1 Windows EXE/Agent 构建通过。严格工具诊断首轮因当前工作树未配置 Wails 路径失败，复用主工作区已安装工具后四项版本全部通过。

补充限制：尝试 `go test -race` 时，本机现有 C 编译器不支持 64 位构建，race runtime 未能构建；没有将这项额外检查记作通过。发布排他锁、取消与释放由上述实际测试验证，不将它等同于 race 检测。

## 尚未覆盖的现场与边界

第三台干净 Windows 的首次准备和 P2.8 组合验收不由本阶段替代。新的原生 Windows 文件对话框现场操作、两台物理机器的本阶段完整操作仍单列待现场核对；浏览器模拟保存框不冒充原生对话框实测。没有实施物理断电或系统盘填满。

本阶段不实现路径自动发布、上传子目录、一发多收、多源或垃圾回收。查询索引不重新读取整份对象，实际传输继续逐块与全文件 SHA-256；不可变副本保留，清理另按引用策略规划。
