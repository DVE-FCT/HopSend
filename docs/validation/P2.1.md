# P2.1 真实 Windows 桌面下载与控制验收

日期：2026-11-23；分支：test/p2.1-desktop-client。

## 交付

- apps/desktop 为实际 Wails 2 + Vue 3 + TypeScript 程序，沿用根 Go 模块与共享应用层；原生 WebView2 窗口，单实例入口。
- 中文设备配置、信任文件选择、配对引用 JSON 导入、真实 HTTPS/SSH 检查、新建下载、任务列表、暂停/继续/取消与本次活动记录。
- 桌面独立 SQLite，保存原 manifest；重开显示真实任务状态，不以演示数据代替进度。
- pnpm 锁文件、固定 Wails 构建脚本，CI 加入 TypeScript/Vite 与实际 Windows 可执行文件构建。
- task:progress 事件载荷 JSON Schema，前端每 750 毫秒读取共享任务快照。

## 自动检查

实际执行 pnpm 冻结依赖安装、vue-tsc、Vite、Wails production 构建，根模块 gofmt/vet/完整测试、CLI/Agent 构建与固定工具链检查均通过。
桌面生成资源不提交 dist、node_modules、wailsjs 或机器凭据；Windows 图标与清单属于可审查构建源材料。

## 原生窗口操作和真实设备

在 Windows 11 / WebView2 的实际 hopsend.exe 窗口操作，使用 Windows computer-use 控件和截图读取验证：

1. 通过原生文件选择器导入本机配对引用 JSON，核对后保存设备。重新启动后设备仍存在。
2. 点击检查连接，界面实际显示 HTTPS 证书、API 凭据、SSH 主机密钥和公钥认证均通过。
3. 在界面填写源端发布的 4 MiB / 4 块版本与目标路径，完成两次真实下载。两份目标大小均为 4,194,304 字节，独立重读 SHA-256 与源端发布前独立哈希一致。
4. 小样本在点击暂停前已完成，完成结果保持 completed；随后改用既有 5 GiB＋17 字节清单专门验证任务控制。
5. 实际大文件任务运行中点击暂停，界面与 SQLite 均为 paused；检查期间暂存前部内容保持不变。
6. 关闭实际窗口并重新启动，原任务仍显示已暂停；点击继续后重新进入下载执行，再通过取消停止。此控制样本未在 GUI 下载全量大文件，避免消耗整份移动数据；大文件完整正确性见 P1.1～P1.3。

发现并修复“已完成瞬间点击旧暂停按钮”误报未运行：对本进程已结束任务的晚到停止请求保持幂等，完整结果不变；补充管理器回归并重新构建实际程序。
远端保持手机热点；临时 Agent 在验证结束后停止。已取消控制样本的测试暂存文件按精确路径清理；真实完成样本和私有验收 JSON 保留在本机输出目录。
