# P0 两设备联调运行手册

这是一份真实设备验收流程。未执行的项目保留待验收，不以本机回环测试代替。

## SSH/SFTP

1. 两台 Windows 分别确定客户端和源节点；源节点使用已有或明确安装的 OpenSSH Server。
2. 创建或使用专用账号，给其配置测试公钥和最小 NTFS 目录权限。不要把管理员私钥放进工程。
3. 在服务端检查主机公钥指纹，经可信渠道在客户端核对 known_hosts；公钥和用户授权是不同事项。
4. 在源节点放置可重复生成的合成 sample.bin，记录指定范围 SHA-256。
5. 先在局域网用 sftp-read 读取该范围，核对字节数和可信预期哈希；再分别试错误主机、错误用户密钥、无权限文件。
6. 运行大范围读取时中断网络或 Ctrl+C，记录超时与取消行为，不宣称存在尚未开发的自动续传。
7. 两端安装并登录 Tailscale 后，用虚拟地址重复读取，记录当前直连/中继与观测时间；不开放公网 SSH。

## HTTPS Agent（在 P0.3 实现后）

接收设备创建独立 TLS 证书与 API 凭据，客户端只接收受信任 CA 公钥和自己的凭据。证书需要包含实际访问的 DNS/IP，不能为通过测试跳过证书验证。
共享目录需明确授权；Agent 的共享权限不会自动改变 SSH 账号权限。配置与操作说明会在 P0.3 补齐。
